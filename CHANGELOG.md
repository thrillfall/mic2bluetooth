# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — Unreleased

Initial release.

- Stream microphone live to a paired Bluetooth speaker (A2DP, default).
- Low-latency Bluetooth SCO mode for headsets and earbuds.
- Toggle and Hold-to-speak (push-to-talk) interaction modes.
- Auto-detection of Bluetooth device connect / disconnect while the app is open.
